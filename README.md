## What I do at IoTides

> **Median reply time dropped from about 7 seconds to about 3 seconds** on a production voice interview agent.

I work on a team building an [AI interview platform and applicant tracking system](https://sabithsb.in/projects/ai-interview/). The platform reads résumés and job descriptions, conducts voice interviews, and gives recruiters a report to review. My work focuses on the voice agent. I measured each step between the end of a candidate's answer and the start of the agent's reply so our team could find and fix the slowest parts.

I also build automated phone systems and test how well AI agents find information and use tools to complete tasks.

## Open-source projects

### [Personal AI Agent](https://github.com/s4b11/livekit-ivr)

I started with a phone receptionist that spoke Malayalam. Today, the same project powers my personal assistant, which answers questions about my work and takes messages. You can reach it over a phone line, in a browser voice app, or through the widget on my portfolio. Those three paths all connect to the same agent, built with LiveKit and Gemini Live.

[Talk to the assistant](https://assistant.sabiii.workers.dev/) · [Read how it works](https://sabithsb.in/projects/ivr-agent/)

### [OKFBench Chat](https://github.com/s4b11/okfbench)

I built this to see how the way I organize a collection of documents changes the evidence an AI assistant finds. Ask a question and compare three approaches: following links between concept pages, looking for relevant keywords, and combining both. Each run shows which sources it used, how long it took, and how many tokens it used.

[Try the demo](https://okfbench-chat.onrender.com/) · [Read the case study](https://sabithsb.in/projects/okfbench/)

### [Utility](https://github.com/s4b11/utility)

I built a private workspace for my tasks, calendar, notes, and encrypted wallet. The assistant asks for approval before it changes anything. For the web version, one Rust component compiled to WebAssembly serves both the app and its API. The same React interface also ships as an Android app with Tauri.

[Read the case study](https://sabithsb.in/projects/utility/)
